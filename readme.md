## Présentation du Projet
Workspace Access Manager est une application web permettant de gérer facilement les employés d’une entreprise, leurs informations et leurs accès aux différentes zones du bâtiment.

Le système offre une interface intuitive permettant d'ajouter des employés, consulter leurs détails, gérer leurs expériences professionnelles et les assigner automatiquement aux salles selon les règles d'accès définies.

## Problématique

Dans plusieurs entreprises, l'organisation du personnel et la gestion d'accès restent encore manuelles.
Cela entraîne :

- Des erreurs d’assignation

- Une perte de temps

- Un manque de visibilité sur qui se trouve dans quelle zone

- Une absence de traçabilité des mouvements

## Solution Proposée

Ce projet apporte une solution simple, dynamique et automatique :

- Interface moderne pour gérer tous les employés

- Assignation intelligente selon les rôles et les salles autorisées

- Sauvegarde automatique avec localStorage

- Visualisation claire de la présence dans chaque salle

- Détails complets des employés via une modal

## Fonctionnalités Principales

- Ajout d’un employé (nom, email, téléphone, photo)

- Ajout illimité d'expériences

- Suppression d’expérience

- Assignation aux zones selon les autorisations

- Suppression d’employé d’une zone

- Affichage détaillé d’un employé

- Filtrage automatique des employés non assignés
